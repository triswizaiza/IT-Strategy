# Triswiza Ariatama | IT Strategy & Transformation Consultant Portfolio

A premium, minimalist, executive-grade portfolio website designed for **Triswiza Ariatama**, an IT Strategy and Transformation Consultant. The platform is engineered to highlight strategic expertise, enterprise architecture frameworks, sanitized client case studies, and corporate credentials with an aesthetic inspired by top-tier global management consulting firms (e.g., McKinsey & Company, BCG, Bain).

---

## 🏛️ Design & Aesthetic Principles

This platform has been designed from the ground up to reflect a highly professional, enterprise-grade tone:
* **Executive Light Theme**: Standard white backgrounds (`#FFFFFF`) paired with deep slate navy typography (`#0F172A`) and subtle warm-grey alternating sections (`#F8FAFC`).
* **High-Contrast Typography**: Elegant, premium serif headers for strategic positioning and clean, highly legible sans-serif typefaces for technical and capability descriptions.
* **Premium Architectural Cards**: Responsive grids with custom rounded corners (`rounded-xl`), soft elevations, and micro-animations to enhance user engagement.
* **Zero Bloat**: Free of generic developer-oriented elements, maintaining a focus on corporate strategy, governance, and organizational impact.

---

## 🛠️ Technology Stack

The project leverages a modern, enterprise-ready web stack:
* **Framework**: [Next.js (App Router)](https://nextjs.org/) for highly performant React-based page rendering and routing.
* **Language**: [TypeScript](https://www.typescriptlang.org/) for robust, type-safe data modeling and component contracts.
* **Styling**: [Tailwind CSS](https://tailwindcss.com/) for fully responsive, modular, utility-first UI design.
* **Quality Assurance**: Strict ESLint checking and TypeScript compiler integration to ensure zero warnings or type errors during build pipelines.

## 📂 Core Architecture & Pages

The application is structured as a multi-page platform, utilizing Next.js's native file-based routing:

### 1. Main Executive Dashboard (`/`)
* **Hero Briefing**: A high-impact overview of core credentials and quantitative metrics (years of experience, global firms covered, and sectors).
* **Expertise Grid**: High-level visual categories of core consulting capabilities.
* **Professional Timeline**: Phased career progression mapping roles at KPMG Indonesia and PwC Indonesia.
* **Proprietary & Standard Frameworks**: Dedicated section showcasing deep familiarity with industry frameworks (TOGAF, COBIT, ITIL, ITMP).
* **Direct Consultation Channel**: A simplified, secure, and direct contact card allowing prospective clients to copy credentials or send a briefing inquiry directly via mail.

### 2. Biography & Leadership Profile (`/about`)
* **Consulting Philosophy**: Insights into strategic business-IT alignment and capability building.
* **Academic Pedigree**: Detailed highlights of Telkom University (B.Eng. Telecommunications, Cum Laude) and Universitas Indonesia (M.Sc. Information Technology).
* **Leadership Record**: Showcasing organizational leadership as Chief Executive of national-scale initiatives (TESLA).

### 3. Sanitized Case Studies (`/case-studies`)
* **Executive Briefings**: Multi-column reports detailing real-world client engagements across Transportation & Aviation, Financial Services, and Automotive sectors.
* **Structured Format**: Each case study is meticulously divided into **Context & Challenge**, **Strategy & Approach**, and **Quantified ROI Outcomes**.
* **NDA Compliance**: Fully anonymized data layers to preserve absolute client confidentiality while clearly demonstrating consulting impact.

### 4. Detailed Service Capabilities (`/expertise`)
* Deep dive into primary consultation offerings: IT Strategy & Roadmaps, Enterprise Architecture Blueprinting, IT Due Diligence, and Change Management.
* Structures specific deliverables, tools, and methodologies (ServiceNow, Power BI, Python, SQL) utilized in active engagements.

## 🚀 Getting Started Locally

To run the portfolio on your local machine, follow these simple steps:

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### 2. Install Dependencies
Clone the repository and install the standard node modules:
```bash
npm install
```

### 3. Launch Development Server
Start the local hot-reloaded development environment:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the live interface.

### 4. Build for Production
Run a full production-ready build to compile and optimize all pages:
```bash
npm run build
```
This generates a highly optimized static build under the `.next` directory.
